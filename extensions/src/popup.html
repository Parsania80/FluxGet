FluxGet

Browser downloads, in one place

Checking connection…

Enabling this profile asks once for access to all websites. Also enable this browser in FluxGet → Settings → Browser downloads.

Left-click: download with FluxGet. Ctrl + left-click: keep that download in your browser. Reload the website after enabling access. Successfully handed-off browser entries are removed from download history.

Website access

Only supported public downloads are captured. To keep downloads from selected hosts in your browser, add them to FluxGet → Settings → Browser downloads → Excluded hosts. Subdomains are included.

Right-click a public link → Send link to FluxGet. Unsupported downloads stay in your browser. Private browsing is disabled.
